# AtriX Tasks — εφαρμογή εργασιών ομάδας (PWA), v1.1

Ημερολόγιο, ατζέντα, ανάθεση εργασιών, «Ολοκληρώθηκε» με σημείωση, ειδοποιήσεις μέσα στην εφαρμογή και Web Push στο κινητό, υπενθύμιση πριν την προθεσμία.

**Τεχνολογίες:** Node.js 18+ · Express · SQLite (better-sqlite3) · web-push · vanilla JS frontend (χωρίς build).

## Τοπική εκτέλεση
```bash
npm install
npm run seed        # δημιουργεί χρήστες + demo εργασίες (node seed.js --reset για καθαρή βάση)
npm start           # http://localhost:3000
```
Αρχικοί χρήστες / PIN (αλλάξτε τα από «Περισσότερα → Αλλαγή PIN»):
PINs: ορίζονται στο env `SEED_PINS` (JSON, π.χ. `{"Admin":"....","Χρήστης":"...."}`), ο πρώτος είναι admin.

Ο διαχειριστής προσθέτει/αφαιρεί μέλη από «Περισσότερα → Ομάδα».

## Κατάσταση ομάδας (live status) — νέο στην v1.1
Κάθε μέλος έχει μία τρέχουσα κατάσταση, ώστε να φαίνεται τι κάνει ο καθένας εκείνη τη στιγμή:

| Κατάσταση | Σημαίνει | Χρώμα |
|---|---|---|
| Ready | Διαθέσιμος | πράσινο |
| Not ready | Μη διαθέσιμος (προεπιλογή) | κόκκινο |
| Break | Διάλειμμα | πορτοκαλί |
| Meeting | Σε meeting | μωβ |
| Call | Σε κλήση | μπλε |
| Καταχώρηση | Καταχώρηση αιτήσεων | τιρκουάζ |

- **Αλλαγή κατάστασης:** το κουμπί με την τελεία στην κεφαλίδα (πάντα ορατό, δείχνει κατάσταση και χρόνο, π.χ. «Call · 12′») → πατάς την κατάσταση που θέλεις. Η σημείωση είναι προαιρετική (π.χ. «πελάτης Σαρόγλου»). Αν πατήσεις ξανά την ίδια κατάσταση, αλλάζει μόνο η σημείωση και ο χρόνος συνεχίζει να μετράει.
- **Καρτέλα «Ομάδα» → «Ομάδα τώρα»:** όλα τα ενεργά μέλη με κατάσταση, σημείωση και πόση ώρα είναι σε αυτήν. Ανανεώνεται αυτόματα κάθε 15″.
- **«Σήμερα» (μόνο για διαχειριστές):** στην ίδια σελίδα, ανά άτομο, πόσα λεπτά πέρασε σε κάθε κατάσταση τη μέρα (ώρα Ελλάδας), ο συνολικός ενεργός χρόνος (όλα εκτός από Not ready) και η πρώτη και τελευταία ενεργή ώρα. Με την ημερομηνία βλέπεις και προηγούμενες μέρες.
- Νέο μέλος ξεκινά σε **Not ready**. Με την **Αποσύνδεση** η κατάσταση γίνεται αυτόματα Not ready. Οι αλλαγές κατάστασης **δεν** στέλνουν ειδοποιήσεις push.
- **Ιστορικό:** ο πίνακας `status_log(user_id, status, note, started_at, ended_at)` κρατά κάθε διάστημα (ώρες σε UTC ISO). Η τρέχουσα κατάσταση είναι η γραμμή με `ended_at IS NULL`. Από εδώ μπορούν αργότερα να βγουν ημερήσιες και μηνιαίες αναφορές ανά άτομο.
- **Προσθήκη κατάστασης:** όλες ορίζονται σε ένα σημείο, στον πίνακα `STATUSES` στο `server.js` (`{ key, label, color }`). Η σειρά του πίνακα είναι και η σειρά εμφάνισης. Μην μετονομάζετε υπάρχοντα `key`, γιατί είναι αποθηκευμένα στο ιστορικό.
- **Βάση:** η μετάβαση είναι ασφαλής. Γίνεται `CREATE TABLE IF NOT EXISTS`, και στήλες προστίθενται μόνο αν λείπουν. Τα υπάρχοντα δεδομένα δεν σβήνονται.

API: `GET /api/statuses` · `GET /api/status/me` · `POST /api/status {status, note}` · `GET /api/team` · `GET /api/status/summary?date=YYYY-MM-DD` (admin).

## Ρυθμίσεις (μεταβλητές περιβάλλοντος)
| Μεταβλητή | Περιγραφή |
|---|---|
| `PORT` | θύρα (προεπιλογή 3000) |
| `DATA_DIR` | φάκελος της βάσης SQLite (προεπιλογή `./data`) — πρέπει να είναι μόνιμος δίσκος |
| `TZ` | **`Europe/Athens`** — οι ώρες εργασιών και οι υπενθυμίσεις υπολογίζονται στη ζώνη του server |
| `VAPID_PUBLIC_KEY` / `VAPID_PRIVATE_KEY` | κλειδιά Web Push. Αν λείπουν, δημιουργούνται αυτόματα μία φορά και αποθηκεύονται στη βάση. Νέα: `npx web-push generate-vapid-keys` |
| `VAPID_SUBJECT` | π.χ. `mailto:info@atrix.com.gr` |

## Ανέβασμα (deploy)
Το Web Push και η εγκατάσταση PWA **απαιτούν HTTPS**.

**VPS (π.χ. Hetzner/DigitalOcean, ~5€/μήνα):**
```bash
git clone … atrix_tasks && cd atrix_tasks && npm ci && npm run seed
sudo npm i -g pm2 && TZ=Europe/Athens pm2 start server.js --name atrix && pm2 save && pm2 startup
```
Μπροστά βάζετε Caddy για αυτόματο HTTPS: `tasks.atrix.com.gr { reverse_proxy localhost:3000 }`.

**Render / Railway:** New Web Service από το repo, Build `npm ci`, Start `npm start`, env `TZ=Europe/Athens`, `DATA_DIR=/data`, και **προσθέστε persistent disk/volume στο `/data`** (αλλιώς η βάση χάνεται σε κάθε deploy). Ορίστε σταθερά VAPID κλειδιά στα env. Τρέξτε `npm run seed` μία φορά από το shell της υπηρεσίας. Στο δωρεάν πλάνο του Render ο server «κοιμάται», οπότε οι υπενθυμίσεις δεν φεύγουν στην ώρα τους — χρειάζεται πληρωμένο instance.

## Εγκατάσταση στο κινητό & ειδοποιήσεις
- **Android (Chrome):** ανοίξτε τη διεύθυνση → «Εγκατάσταση εφαρμογής». Μετά «Περισσότερα → Ενεργοποίηση ειδοποιήσεων».
- **iPhone:** τα push λειτουργούν **μόνο σε iOS 16.4+ και μόνο αφού η εφαρμογή προστεθεί στην οθόνη Αφετηρίας**: Safari → Κοινοποίηση → «Προσθήκη στην οθόνη Αφετηρίας», άνοιγμα από το εικονίδιο, και μετά «Ενεργοποίηση ειδοποιήσεων». Κάθε μέλος το κάνει στη δική του συσκευή.

Ειδοποιήσεις: ο ανατεθειμένος ειδοποιείται όταν του δοθεί εργασία· ο δημιουργός και οι admins όταν ολοκληρωθεί· ο ανατεθειμένος λαμβάνει υπενθύμιση Χ λεπτά πριν την προθεσμία (έλεγχος κάθε λεπτό).
